# Utils Service

Utility-grade FastAPI service for watchlist hosting at `utils.nitrowager.bet`.

## Features

- **GET /api/watchlist** — Returns watchlist entries as JSON (or HTML fallback)
- **POST /api/watchlist/refresh** — Triggers k8s Job to regenerate watchlist CSV
- **Session auth** — Mirrors tracks backend auth (shared secret key)

## Development

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
```

## Running Locally

```bash
export NITRO_AUTH_PASSWORD="your-password"
export NITRO_WATCHLIST_CSV_PATH="/path/to/netlist-latest.csv"
uvicorn nitro_utils.main:app --reload
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `NITRO_AUTH_PASSWORD` | `""` | Password for cookie auth (empty = auth disabled) |
| `NITRO_AUTH_SECRET_KEY` | dev key | Secret key for session tokens (MUST match tracks in prod) |
| `NITRO_AUTH_COOKIE_SECURE` | `true` | Require HTTPS for cookies |
| `NITRO_WATCHLIST_CSV_PATH` | `/shared/watchlist/netlist-latest.csv` | Path to watchlist CSV |
| `NITRO_K8S_NAMESPACE` | `nitro` | Namespace for refresh Jobs |
| `NITRO_K8S_JOB_IMAGE` | `gcr.io/nitro-wagering/paper-monitor:latest` | Image for refresh Job |
| `NITRO_LOG_LEVEL` | `INFO` | Logging level |

## Deployment

Built and deployed via GitHub Actions. Image: `gcr.io/nitro-wagering/utils-service:latest`

### k8s Requirements

- **Service account** with `batch/v1` Job create permission
- **Volume mount**: `nitro-shared` PVC at `/shared`
- **Ingress**: `utils.nitrowager.bet` → service port 8000

See `k8s/` directory for manifests.

## Integration

Watchlist data generated by `paper-monitor` pod script (`/tmp/build_watchlist_final.py`). POST /refresh creates k8s Job running that script, which writes to `/shared/watchlist/netlist-latest.csv`. GET /watchlist reads and parses that CSV.
